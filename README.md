# نظام إدارة العيادة - Clinic Management System

تطبيق مكتبي متكامل لإدارة العيادات الطبية، يهدف إلى تنظيم عمليات العيادة مثل إدارة المرضى، المواعيد، الزيارات، المستخدمين، والصلاحيات.  
تم تطوير هذا المشروع باستخدام لغة C# وقاعدة بيانات SQL Server ضمن مشروع تخرج جامعي.

## المميزات
- تسجيل المرضى وإدارة ملفاتهم الطبية
- إدارة المواعيد وجدولتها
- تسجيل الزيارات وأنواع الزيارات
- نظام مستخدمين مع صلاحيات (Roles)
- سجل نشاطات (Logs) لتتبع العمليات
- قاعدة بيانات مصممة وفق معايير ERD احترافية

## التقنيات المستخدمة
- C# (Windows Forms)
- SQL Server
- ADO.NET
- Git & GitHub

## هدف المشروع
يهدف المشروع إلى تقديم نظام عملي لإدارة العيادات، وإظهار مهارات في:
- تحليل الأنظمة
- تصميم قواعد البيانات
- تطوير تطبيقات سطح المكتب
- كتابة التوثيق الفني

## طريقة التشغيل
1. استعادة قاعدة البيانات من سكربت SQL المرفق.
2. فتح المشروع عبر Visual Studio.
3. تعديل Connection String إذا لزم الأمر.
4. تشغيل التطبيق.
